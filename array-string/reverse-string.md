Approach

We use two pointers, one at the beginning and one at the end of the string. We swap the characters and move both pointers towards the center until the complete string is reversed.

Complexity
Time: O(n)
Space: O(1)
Notes
The string is reversed in-place.
Two pointers are used to swap characters.
An empty string or a string with one character does not need any changes.
Local test cases were used before submitting the solution.
